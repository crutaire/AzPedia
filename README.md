# AzPedia
AzPedia - Addon to find cheaper flight paths in WoW Forever

If a cheaper route is available it will display the route in the tooltip for the flight destination.

It builds up the database of flight costs over time as you visit each flight master, so initially you will not see any savings recommendations in the flight tips. Costs are based on reputation with factions so this is built up and stored individually for each character.

To get help type: /azp help in chat
